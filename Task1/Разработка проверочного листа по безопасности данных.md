# Проверочный лист по безопасности данных для PropDevelopment

Данный документ включает классификацию данных, определение рисков, оценку риска.

---

## 1. Классификация данных по ISO/IEC 27001 и 27002

### 1.1 Публичные данные
- **Примеры:**  
  • Маркетинговые материалы  
  • Описание объектов недвижимости  
  • Публично доступные цены  
- **Риск:** Искажение данных  
  - **Оценка риска:** Значительный  
  - **Объяснение:** Некорректное отображение публичной информации может ввести клиентов в заблуждение, что негативно скажется на доверии к компании.

### 1.2 Внутренние данные
- **Примеры:**  
  • Данные внутренних процессов  
  • Расписания, технические конфигурации IT-систем  
  • Отчёты операционной деятельности  
- **Риск:** Потеря данных  
  - **Оценка риска:** Значительный  
  - **Объяснение:** Потеря внутренних данных может привести к срывам в операционной деятельности и затруднить оперативное управление.

### 1.3 Конфиденциальные данные
- **Примеры:**  
  • Персональные данные клиентов и собственников (ФИО, телефон, email, расширенные анкеты)  
  • Финансовая информация по сделкам  
  • Результаты осмотров объектов недвижимости  
- **Риск:** Утечка данных  
  - **Оценка риска:** Критический  
  - **Объяснение:** Утечка персональных и финансовых данных может привести к юридическим проблемам и серьёзным потерям доверия со стороны клиентов.

### 1.4 Секретные данные
- **Примеры:**  
  • Стратегические данные компании  
  • Детали интеграций с госорганами и API партнёров  
  • Информация об уязвимостях IT-систем и внутренних протоколах безопасности  
- **Риск:** Обесценивание данных  
  - **Оценка риска:** Критический  
  - **Объяснение:** Раскрытие секретных данных снижает их стратегическую ценность, что может привести к потере конкурентного преимущества.
